# QueryLanguage
Консольное Java-приложение, эмулирующее небольшой язык запросов (в духе SQL) для работы с in-memory базой данных товаров.
 
Учебный проект, НИУ ВШЭ.
 
## Что умеет программа
 
Приложение читает команды из консоли построчно, выполняет их над базой данных товаров (`Product`: `id`, `name`, `manufacturer`, `city`, `quantity`) и печатает результат.
 
Поддерживаемые команды:
 
- **`SELECT`** — выборка данных.
  - `SELECT *` или `SELECT (поле, поле, ...)` — выбор всех полей или конкретных.
  - `FILTER(поле, значение)` — фильтрация по точному совпадению значения поля; можно указывать несколько раз подряд.
  - `ORDER(поле, ASC|DESC)` — сортировка по возрастанию/убыванию; встречается не более одного раза. При отсутствии — сортировка по `id`.
- **`INSERT (name, manufacturer, city, quantity)`** — добавление нового товара.
- **`REMOVE id`** — удаление товара по идентификатору.
- **`CLEAR`** — очистка базы данных.
Названия команд и подкоманд (`SELECT`, `FILTER`, `ORDER`) регистронезависимы, значения `ASC`/`DESC` и имена полей — регистрозависимы. Некорректные запросы не приводят к падению программы — выводится сообщение об ошибке, работа продолжается.
 
## Запуск
 
Проект рассчитан на компиляцию и запуск через IntelliJ IDEA (JDK 21, без систем сборки).
 
```
java querylang.Main
```
 
Команды вводятся построчно в стандартный поток ввода, результат выполнения каждой печатается сразу после ввода.
 
Пример:
 
```
SELECT *
0, Гитара, Yamaha, Tokyo, 12
INSERT (Пирожок с мясом, X5 Retail Group, Moscow, 12)
Product with id 1 was added successfully
SELECT (name) FILTER(city, Moscow)
Пирожок с мясом
REMOVE 0
Product with id 0 was removed successfully
CLEAR
1 products were removed successfully
```
 
## Структура проекта
 
```
src/querylang/
├── Main.java             # точка входа (часть шаблона, не изменялась)
├── db/                    # Database, Product (часть шаблона, не изменялись)
├── parsing/               # QueryParser и парсеры отдельных команд, ParsingResult, Field
├── queries/               # Query и реализации (SelectQuery, InsertQuery, RemoveQuery, ClearQuery)
├── result/                # QueryResult и реализации результатов выполнения команд
└── util/                  # FieldGetter — функциональный интерфейс для доступа к полям товара
 
test/querylang/            # модульные тесты (JUnit 5), структура повторяет src/
```
 
## Тестирование
 
Модульные тесты написаны на JUnit 5 и находятся в каталоге `test/`. Каждый тест проверяет одну конкретную вещь и не зависит от порядка запуска остальных тестов.
 
## Ограничения задания
 
Проект использует только стандартную библиотеку Java (21) и JUnit 5
